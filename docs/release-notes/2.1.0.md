# Release notes — Peisar 2.1.0

**Release date: unreleased · Tag: `2.1.0` · Compare:
[2.0.1...2.1.0](https://github.com/phothinmg/peisar/compare/2.0.1...2.1.0)**

Peisar 2.1.0 fixes GFM table cell parsing and inline source positions for
multibyte UTF-8 text.

## Fixes

- Escaped pipes (`\|`) remain within table cells and render as literal pipes.
- A GFM table is recognized only when the header and delimiter rows have the
  same number of columns.
- Inline node end positions now use the correct UTF-8 byte offset.
- Backslash-escaped ASCII punctuation is emitted as literal text.

## Upgrade

```toml
[dependencies]
peisar = "2.1.0"
```

```sh
npm i peisar@2.1.0
```
