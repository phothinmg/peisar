# Release notes — Peisar 2.0.1

**Release date: 2026-11-04 · Tag: `2.0.1` · Compare:
[2.0.0...2.0.1](https://github.com/phothinmg/peisar/compare/2.0.0...2.0.1)**

Peisar 2.0.1 simplifies the Rust crate configuration and aligns its documented
API with the current Rust exports.

## Rust API changes

The `peisar::ast` and `peisar::plugin` modules are available without Cargo
feature flags. The crate's only optional Cargo feature is `npm`, which enables
the N-API bindings used to build the Node.js package. Ordinary Rust usage
remains. The crate now uses the published `peisar_ast` 1.2.15 dependency
instead of a local path dependency and no longer directly depends on
`peisar_yaml`.

```toml
[dependencies]
peisar = "2.0.1"
```

AST node types are re-exported from `peisar::ast`. Use `Document::parse` for
direct parsing or `md_to_ast_with_hooks` when custom parser hooks are needed.
HTML rendering and front matter are available through the high-level
`Peisar` API.

The `peisar::parsers` and `peisar::yaml` modules, and the `PeisarAst` and
`md_to_ast` re-exports, are removed. Rust code using those APIs should migrate
to the public AST types and parsing helpers; front matter consumers should use
`Peisar::frontmatter()`.
